Aja como um Engenheiro Frontend Sênior e Especialista em UI/UX.

### Objetivo
Crie um protótipo funcional em arquivo único (HTML + Tailwind CSS + JavaScript puro) para a validação de MVP da rede social **MOODLAP**.

### Contexto do Produto
O **MOODLAP** é uma plataforma focada no registro do humor diário e no compartilhamento de micro-momentos do cotidiano chamados de "LAPs" (posts com imagem, legenda e indicador de humor).

### Identidade Visual & Design System
- **Paleta de cores:** Tons de roxo (primário/destaque) e azul-marinho (fundo e superfícies), com tipografia limpa em branco e cinza-claro.
- **Estilo:** Interface moderna, com cantos arredondados, sombras suaves e microinterações táteis.
- **Responsividade:** Layout mobile-first, com suporte a visualização desktop centralizada.

### Requisitos Funcionais do Protótipo
1. **Perfil de Usuário (Header/Sidebar):** Exibir avatar, nome (@handle), bio curta e seletor rápido de humor atual (ex.: radiante, calmo, exausto, ansioso).
2. **Feed de "LAPs":**
   - Card de postagem contendo: autor, avatar, tag de humor do post, foto (use Unsplash via placeholder URL), texto descritivo e timestamp.
   - Ações interativas no card: botões funcionais de like, dislike, abrir modal/seção de comentários e botão de denúncia ("Reportar conteúdo").
3. **Interatividade Mínima:**
   - Incrementar/decrementar contadores de likes e dislikes ao clicar.
   - Formulário básico para postar um novo "LAP" (com seleção de humor e upload simulado).
   - Feedback visual (toast/alerta amigável) ao acionar a denúncia de post.

### Dados de Apresentação (Mock Data)
Popule a interface com 3 a 4 contas fictícias pré-carregadas com dados consistentes para uma demo executiva:
- Cada conta deve ter: nome, handle, avatar realista, bio condizente e ao menos 1 LAP publicado no feed com humores contrastantes (ex.: um dia produtivo vs. um dia caótico).
